## Ekran Envanteri

RepoWarden penceresiz bir Node.js komut satırı aracıdır. Arayüzü terminal çıktısıdır.

| Ekran | Hâl | Düzene Geçti |
|---|---|---|
| `--help` yardım metni | dinlenik | Evet: başlık `renk-1`, bölüm adları `text-label` |
| Denetim ilerlemesi (stderr, depo başına satır) | yükleme | Evet: sayı en kötü önem rengini alır |
| Rapor (stdout) | dolu | Evet: başlıklar `renk-1`, önem sözcükleri rol renginden |
| Rapor | boş (temiz hesap) | Evet: `ok` → `success` |
| Sahip yok hatası | hata | Evet: `danger-text` |
| Rapor yolu satırı | sonuç | Evet: `success` |
| GitHub issue etiketi | uzak | Evet: elle yazılmış `c67eff` yerine `renk-3` token'ı |

`NO_COLOR`, `TERM=dumb` ya da yönlendirilmiş çıktıda renk basılmaz; rapor dosyası düz Markdown kalır.
