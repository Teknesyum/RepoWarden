# RepoWarden

Windows tray app that watches open issues, plus a Node.js CLI that audits every repository on a GitHub account. Both go through `gh`.

- `bin/repowarden.mjs` the whole audit; `bin/tema.mjs` terminal colours from `teknesyum-ui/theme.tokens.json`.
- `src/RepoWarden.cs` the tray app (.NET Framework 4 WinForms, one file); `build.ps1` compiles it to `dist/RepoWarden.exe`. Version is `Surum` in that file.
- `RepoWarden.exe --goruntu <dir>` writes the menu and icon states as PNG and exits; that is the UI test.
- `teknesyum-ui/` is generated by teknesyum-ui `setup.js --apply`; never edit by hand.
- `assets/icon/` is generated by `node scripts/icon.mjs` from the tokens.
- Base reads `.teknesyum/`: `teknesyum.json`, `icon.png`, `shot.jpg`, `full.jpg`. `scripts/shot.ps1` regenerates the images after a build; keep both manifests in step.
- `teknesyum.json` makes the repo installable from Teknesyum Base (zip, runs `RepoWarden.exe`).
- Release: `build.ps1`, then `node scripts/pack.mjs <x.y.z>` → `dist/`, then `gh release create v<x.y.z> dist/*.zip`.
- Git content is English; working papers stay in ignored paths. Finished files move to `trash/`.
